# POC NestJS

API de prova de conceito construída com NestJS para experimentar a estrutura modular do framework e endpoints HTTP em Node.js/TypeScript.

## Stack
- Node.js
- NestJS
- TypeScript

## Como executar

```bash
npm install
npm run start:dev
```

Os comandos disponíveis dependem dos scripts definidos em `package.json`; a compilação padrão do NestJS usa `npm run build`.
